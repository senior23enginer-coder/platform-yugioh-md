# Criterios de aceptacion

## Catalogo

- [ ] Produccion lista 54 decks: 43 TCG, 7 GOAT y 4 Rush Duel.
- [ ] Cada deck activo tiene equipo.
- [ ] Filtros de deck/equipo separan todos los formatos.
- [ ] Los siete GOAT aparecen al filtrar GOAT.
- [ ] No se inventan cartas, multimedia ni datos historicos ausentes.

## Eventos

- [ ] Se pueden crear los ocho tipos base con configuracion editable.
- [ ] Liga exige division.
- [ ] Selector, pestañas, tabla y resultados usan el mismo evento seleccionado.
- [ ] Programacion persiste y `Comenzar` respeta fecha/hora.
- [ ] Eliminacion muestra confirmacion.
- [ ] Amistoso manual puede eliminarse.
- [ ] Cierre congela resumen, clasificacion, campeon, metagame y PDF.

## Duelo

- [ ] Empate de dados fuerza nuevo lanzamiento.
- [ ] Perdedor del duelo anterior decide el siguiente inicio.
- [ ] Empate de duelo fuerza dados para el siguiente.
- [ ] No se comienza sin lado inicial.
- [ ] Reloj/sin reloj queda bloqueado al comenzar.
- [ ] Turnos solo aumentan y quedan auditados.
- [ ] Calculadora cambia y sincroniza LP.
- [ ] El lado sin turno no puede rendirse desde su pantalla ni guardar una rendicion desde la consola.
- [ ] La rendicion del lado activo pide confirmacion, sincroniza ganador y motivo, y detiene el reloj.
- [ ] La calculadora estandar resuelve suma, resta, multiplicacion y division y permite usar el resultado como valor LP.
- [ ] Elegir ganador no recarga antes del guardado explicito.
- [ ] BO5 no cierra como BO3 cuando la regla contiene D4/D5.
- [ ] Un match finalizado no habilita duelos adicionales.
- [ ] Cada duelo finalizado abre su detalle con `Ver`.

## Inteligencia

- [ ] Rankings global, temporada, historico, formato, evento, division, Elo, power y consistencia usan datos persistidos.
- [ ] Movimiento historico usa posicion real, no solo variacion Elo.
- [ ] Metagame usa partidas finalizadas y explica formula/muestra.
- [ ] Tiers Zero/1/2/3 y rendimiento por tier estan separados.
- [ ] Matriz completa de matchups muestra rival, volumen y winrate.
- [ ] Tops aplican muestra minima configurable.

## Datos y reportes

- [ ] Snapshot conserva deck, equipo, formato, regla y cartas disponibles al jugar.
- [ ] Origen capturado/agregado/inferido es visible.
- [ ] Exportaciones generales e individuales funcionan en CSV, Excel y PDF.
- [ ] Vista publica de temporada y marcador publico no muestran controles administrativos.
- [ ] Cola offline no pierde resultados y detecta conflictos.

## Responsive

- [ ] Flujo completo D1-D5 funciona en Galaxy S25 Ultra vertical y horizontal.
- [ ] 1v1, 2v2, 3v3 y cinco decks no desbordan.
- [ ] No hay controles superpuestos, texto ilegible ni scroll horizontal accidental.
